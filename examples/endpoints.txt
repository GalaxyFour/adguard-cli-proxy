# Endpoint label format:
#   {ip}:{port}/{ISO}/{CITY-SLUG}
#
# The suffix is a location label. The proxy itself is SOCKS5 at {ip}:{port}.
# Generate the real values with:
#   adguard-cli-proxy up US/LAS-VEGAS --instance us-las-vegas --port 9112
#   adguard-cli-proxy up ID/JAKARTA  --instance id-jakarta  --port 9113
#
# Or let the gateway map a request to a backend in 9112-9222:
#   curl http://127.0.0.1:9111/US/LAS-VEGAS
#
# 9router/undici pools reject paths, so use the gateway's pathless pool URLs:
#   curl http://127.0.0.1:9111/_9router
#   curl 'http://127.0.0.1:9111/US/LAS-VEGAS?format=9router'
